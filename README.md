# Simple Hair Cards

A curve-based hair card editor for Blender — draw strands, comb them with
dedicated brushes, weave real braids, and generate ready-to-export texture
maps for your game or character, all within Blender's workflow.

## Documentation

Full documentation (installation, every tool explained, keyboard shortcuts,
known limitations) — available in Portuguese and English:

https://esaque0000.github.io/simple-hair-cards-docs/
